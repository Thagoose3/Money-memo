# 💰 Smart Expense & Budget (แอพบริหารรายรับ-รายจ่าย & วิเคราะห์งบประมาณ)

เว็บแอปพลิเคชันบริหารจัดการการเงินส่วนบุคคลแบบครบวงจร ใช้งานง่าย สวยงาม ทันสมัย รองรับภาษาไทยสมบูรณ์แบบ ทำงานได้ทั้งบนมือถือและคอมพิวเตอร์แบบ Offline โดยไม่ต้องติดตั้งโปรแกรมหรือเซิร์ฟเวอร์ใดๆ

---

## 🌟 ฟังก์ชันเด่นทั้งหมดในระบบ

### 1. 📝 บันทึกรายรับ-รายจ่ายที่แม่นยำและง่ายดาย
- **สลับประเภทได้ใน 1 คลิก**: เลือกระหว่าง **🔴 รายจ่าย (Expense)** หรือ **🟢 รายรับ (Income)**
- **ปุ่มลัดตัวเลขยอดเงิน (Quick Amount Chips)**: กดเพิ่มยอดเงินด่วน `+50`, `+100`, `+500`, `+1,000`, `+2,000`
- **วันที่-เวลาอัจฉริยะ**: ตั้งเป็นวันและเวลาปัจจุบันให้อัตโนมัติ สามารถเปลี่ยนย้อนหลังได้
- **ช่องทางชำระเงิน**: เงินสด, พร้อมเพย์/สแกน QR, โอนเงินผ่านธนาคาร, บัตรเครดิต, E-Wallet
- **หมวดหมู่ไอคอน Emoji**: เลือกหมวดหมู่พร้อมไอคอน Emoji สวยงาม และช่องบันทึกช่วยจำ (Note)

### 2. 📊 แดชบอร์ดสรุปรายวันและรายเดือน (Dashboard)
- **แถบเลือกเดือนและปุ่มเลื่อน `< >`**: เลื่อนดูข้อมูลย้อนหลังหรือล่วงหน้าได้ตามต้องการ พร้อมปุ่มกลับมาเดือนปัจจุบัน
- **3 บัตรสรุปหลัก (KPI Summary Cards)**:
  - 🟢 **รายรับรวม (Total Income)**
  - 🔴 **รายจ่ายรวม (Total Expense)**
  - 💰 **ยอดเงินคงเหลือสุทธิ (Net Balance)** พร้อมแสดงสถานะสภาพคล่อง (Surplus / Deficit)
- **2 โหมดมุมมอง (View Modes)**:
  - **📊 สรุปภาพรวมรายเดือน (Monthly Overview)**:
    - กราฟวงกลม Doughnut Chart แจกแจงสัดส่วนรายจ่ายตามหมวดหมู่ (%)
    - รายการ 5 อันดับหมวดหมู่รายจ่ายสูงสุด พร้อมแถบสีความคืบหน้า
    - กราฟแท่ง Daily Spending & Income Trend แสดงแนวโน้มการใช้เงินในแต่ละวันตลอดทั้งเดือน
  - **📅 แจกแจงรายวัน (Daily Breakdown)**:
    - จัดกลุ่มรายการตามวัน (Grouped by Date)
    - แสดงยอดรวมรายรับและรายจ่ายประจำวันชัดเจน
    - รายการย่อยในแต่ละวัน พร้อม Badge หมวดหมู่, ช่องทางชำระเงิน, เวลา, และปุ่มแก้ไข/ลบ

### 3. 🏷️ ระบบเพิ่มและจัดการหมวดหมู่ได้เอง
- มีหมวดหมู่พื้นฐานครอบคลุมทั้งรายรับและรายจ่าย
- ปุ่ม **"+ สร้างหมวดหมู่ใหม่"**: ตั้งชื่อ, เลือกประเภทรายรับ/รายจ่าย, เลือก Emoji, และเลือกสีประจำหมวดหมู่ได้เอง
- สามารถลบหมวดหมู่ที่สร้างขึ้นเองได้อย่างปลอดภัย

### 4. ✏️ แก้ไขและลบรายการอย่างปลอดภัย
- **ปุ่มแก้ไข (Edit)**: เปิดหน้าต่าง Modal ให้ปรับปรุงตัวเลข, วันที่, ช่องทางชำระเงิน, หมวดหมู่ และโน้ตย้อนหลังได้ตลอดเวลา
- **ปุ่มลบ (Delete)**: มีกล่องแจ้งเตือนถามยืนยันความปลอดภัย (Safe Confirmation Dialog) พร้อมแสดงรายละเอียดรายการก่อนลบจริง
- **ระบบค้นหาและกรอง (Search & Filter)**: ค้นหาตามคำในโน้ต, ชื่อหมวดหมู่, ช่องทางชำระเงิน และกรองประเภทรายรับ/รายจ่าย
- **ส่งออกและสำรองข้อมูล**:
  - ส่งออกเป็นไฟล์ **Excel / CSV ภาษาไทย** ด้วยรหัส UTF-8 with BOM (เปิดใน Microsoft Excel แล้วภาษาไทยไม่เพี้ยน)
  - ส่งออกและนำเข้าไฟล์ **JSON Backup** สำหรับสำรองหรือย้ายเครื่อง
  - ปุ่ม **โหลดข้อมูลตัวอย่าง (Sample Demo Data)** สำหรับทดลองใช้งานได้ทันที

### 5. 🧮 หน้าวิเคราะห์การบริหารเงิน & คำนวณเงินกินใช้วันละกี่บาท (Budget Simulator)
- **ระบบจำลองงบประมาณล่วงหน้าแบบแยกอิสระ**:
  - กรอก **รายได้ตั้งต้นต่อเดือน** (เช่น ฿28,000)
  - กรอก **เป้าหมายเงินออม** (เช่น ฿4,000 หรือปรับตามต้องการ)
  - กรอก **รายจ่ายประจำเดือน (Fixed Expenses)** เช่น ค่าเช่าห้อง, ค่าน้ำไฟ, ค่าเน็ต, ค่าเดินทางประจำ, ค่าซักผ้า, สมาชิกรายเดือน (เพิ่ม/ลบแถวได้อย่างอิสระ)
  - เลือกจำนวนวันในเดือน (30, 31 หรือ 28 วัน)
- **คำนวณและวิเคราะห์ผลลัพธ์ทันที**:
  - 💵 **ยอดรวมรายจ่ายประจำเดือน**
  - 💰 **เงินคงเหลือสำหรับกินใช้จริงทั้งเดือน (Remaining Monthly Allowance)**
  - 🌟 **ค่าเฉลี่ยเงินที่ใช้ได้ตกวันละกี่บาท (Daily Allowance)** เช่น *"คุณมีเงินใช้ได้เฉลี่ยวันละ ฿460.00"*
  - ⏱️ **สัปดาห์ละกี่บาท (Weekly Allowance)**
  - 📊 **แถบสัดส่วนกฎ 50/30/20 (Needs / Wants / Savings)**
  - 💡 **Financial Health Score**: ประเมินระดับสุขภาพการเงิน (ยอดเยี่ยม, สมดุล, ค่อนข้างตึงตัว, หรือติดลบ) พร้อมคำแนะนำเชิงปฏิบัติการ

## 🚀 วิธีเปิดใช้งาน

1. ดับเบิลคลิกที่ไฟล์ `launch.bat` เพื่อเปิดเว็บแอปพลิเคชันบนเบราว์เซอร์ทันที (เช่น Google Chrome, Microsoft Edge, Safari)
2. หรือดับเบิลคลิกเปิดไฟล์ `index.html` ได้โดยตรง
3. สามารถกดปุ่ม **"✨ โหลดข้อมูลตัวอย่าง"** ที่แถบเมนูด้านบน เพื่อดูตัวอย่างกราฟและรายงานได้ทันที
